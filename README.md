  <h1>🌐 Static Website Hosting with AWS S3 and CloudFront</h1>

  <p>This project demonstrates how to host a static website using AWS services. It uses an Amazon S3 bucket for file storage and CloudFront as a CDN for global distribution.</p>

  <h2>🚀 Project Overview</h2>
  <ul>
    <li>Host a simple HTML website</li>
    <li>Enable static website hosting via AWS S3</li>
    <li>Distribute the website globally using AWS CloudFront</li>
  </ul>

  <h2>🛠️ Technologies Used</h2>
  <ul>
    <li>HTML5</li>
    <li>Amazon S3</li>
    <li>AWS CloudFront</li>
  </ul>
